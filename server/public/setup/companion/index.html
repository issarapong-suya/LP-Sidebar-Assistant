จัดการ Companion

ติดตั้งจากหน้า /install/ ได้โดยตรง ไม่ต้องกรอก URL หรือ activation code และเพิกถอนเครื่องที่ไม่ใช้งานได้จากหน้านี้

ติดตั้งเครื่องใหม่

เปิด HOSxP แล้วดาวน์โหลด Companion จากหน้า Install บนเครื่องนั้น จากนั้นเปิดไฟล์ที่ดาวน์โหลด โปรแกรมจะอ่าน Server URL จากลิงก์ดาวน์โหลดและลงทะเบียนเครื่องอัตโนมัติ

ไปหน้าดาวน์โหลด Companion
เครื่องต้องอยู่ในเครือข่ายที่อนุญาต; workstation ใช้ HTTPS ส่วน localhost ใช้ HTTP ได้ โปรแกรมจัดการ token เบื้องหลังและบันทึกชื่อเครื่องในรายการด้านขวา

เครื่องที่ลงทะเบียนแล้ว

ดูสถานะและเพิกถอน token รายเครื่องได้จากที่นี่

หน้า Setup เปิดได้เฉพาะบนเครื่อง Servertoken ภายในไม่แสดงบนหน้าเว็บหรือ audit log
