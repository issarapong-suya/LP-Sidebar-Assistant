จัดการ Companion

ตรวจสอบสถานะออนไลน์ IP เครื่องจริง และเพิกถอนเครื่องที่ไม่ใช้งานได้จากหน้านี้

ติดตั้งเครื่องใหม่

เปิด HOSxP แล้วเปิดหน้า Install บนเครื่องนั้นเพื่อดาวน์โหลดโปรแกรมติดตั้ง Companion ระบบจะอ่าน Server URL และลงทะเบียนอัตโนมัติ

ไปหน้าดาวน์โหลด Companion
หมายเหตุ:
• เครื่องลูกในวง LAN สามารถใช้งานผ่าน HTTP หรือ HTTPS ตามที่อนุญาต
• ระบบจะแสดงทั้งชื่อเครื่อง (Computer Name), IP เครื่องลูกจริง, และ IP Socket Gateway (หากวิ่งผ่าน NAT/Firewall)

เครื่องที่ลงทะเบียนแล้ว

ดูสถานะออนไลน์ IP เครื่องลูก และเพิกถอน token รายเครื่อง

🔍
แสดง 0-0 จาก 0 เครื่อง
หน้า Setup เปิดได้เฉพาะบนเครื่อง Server หรือวงเครือข่ายที่อนุญาต Token ภายในถูกจัดเก็บแบบ Secure Hash และไม่แสดงในหน้าเว็บ
