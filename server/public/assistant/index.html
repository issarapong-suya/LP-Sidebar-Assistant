Sidebar Doctor Assistant v1

การใช้และดูแลข้อมูลในระบบนี้

Sidebar Doctor Assistant อ่านข้อมูลจากฐาน HOSxP ด้วยบัญชีฐานข้อมูลที่กำหนดสิทธิ์อ่านอย่างเดียว เพื่อแสดงข้อมูลของผู้ป่วยที่เลือก เช่น ประวัติแพ้ยา ผลตรวจทางห้องปฏิบัติการ สัญญาณชีพ ยาที่ได้รับ และประวัติการรักษา รวมถึงคำนวณค่าประกอบการดูแล เช่น eGFR และ CrCl ข้อมูลนี้มีไว้ช่วยประกอบการพิจารณาของบุคลากรทางการแพทย์ ไม่ใช้แทนดุลยพินิจของผู้รักษา

เมื่อเข้าสู่ระบบโดยไม่เปิด HOSxP ระบบตรวจบัญชีผู้ใช้กับตาราง opduser ผ่าน passweb ข้อมูลรหัสผ่านที่กรอกใช้เพื่อตรวจสอบและไม่ถูกบันทึกเป็นข้อมูลบัญชีใน Sidebar เมื่อระบบพบ session จาก HOSxP/Companion จะออกจาก manual session และเปลี่ยนไปใช้ผู้ใช้กับคนไข้ที่เลือกใน HOSxP ผู้ใช้ควรออกจากระบบเมื่อเลิกใช้งาน และไม่ใช้บัญชีร่วมกัน

ระบบบันทึกเหตุการณ์เข้าใช้ ค้นหา เปิดดูข้อมูล และออกจากระบบ พร้อมบัญชีผู้ใช้ เครื่อง และ IP โดยแทน HN/VN ใน audit log ด้วยรหัสอ้างอิงที่ผ่าน HMAC ไฟล์ audit จัดเก็บใน SQLite บนเครื่อง Server และมี JSONL สำรองเมื่อ SQLite เขียนไม่ได้ ข้อมูลผู้ป่วยที่กำลังแสดงใช้ในหน่วยความจำระหว่างทำงาน ระบบนี้ไม่ส่งข้อมูลให้ AI หรือบริการภายนอก

การเชื่อมต่อจากเครื่องอื่นต้องใช้ HTTPS ผู้ดูแลระบบโรงพยาบาลเป็นผู้กำหนดสิทธิ์เข้าถึงระบบ การสำรอง และระยะเวลาเก็บ audit log ให้สอดคล้องกับนโยบายของโรงพยาบาล หากพบการใช้ข้อมูลผิดวัตถุประสงค์ โปรดแจ้งผู้ดูแลระบบหรือเจ้าหน้าที่คุ้มครองข้อมูลของโรงพยาบาล
