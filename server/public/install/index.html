🛡️
คำแนะนำกรณี Windows แสดงหน้าต่างสีฟ้า "Windows protected your PC":
เนื่องจากเป็นโปรแกรมภายในโรงพยาบาล ให้คลิกที่ข้อความ More info (ข้อมูลเพิ่มเติม) แล้วเลือกปุ่ม Run anyway (ทำงานต่อไป) โปรแกรมจะเริ่มทำงานทันที
การลงทะเบียนจากเครื่องตรวจต้องเปิดผ่าน HTTPS หรืออยู่ในเครือข่าย LAN ที่ได้รับอนุญาต (สำหรับการทดสอบบน Server รองรับ localhost ได้)
โปรแกรมทำงานแบบ Read-only ดึงข้อมูลประกอบการตัดสินใจจาก HOSxP เท่านั้น · ไม่มีการเขียนหรือแก้ไขเวชระเบียน
